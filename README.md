# 🌍 TravelGo – Travel Website

TravelGo is a modern responsive travel website built using Flask, HTML, CSS, and JavaScript.  
It allows users to explore destinations, view travel packages, and contact the company through a clean and interactive interface.

The project focuses on responsive design, UI/UX principles, and frontend-backend integration using Flask.

---

## ✨ Features

- Responsive design for mobile, tablet, and desktop
- Dynamic navigation with hamburger menu
- Destination cards with images and descriptions
- Travel package listings
- About section with company details
- Contact form connected to MySQL database
- Smooth UI with modern gradients and hover effects

---

## 🛠 Tech Stack

- Python (Flask)
- HTML5
- CSS3
- JavaScript
- MySQL
